# **Pibic-Pibiti-Huac**

Esta é uma organização que concentra repositórios com dados e códigos produzidos durante projeto de pesquisa **PIBIC/PIBITI**, desenvolvido na Universidade Federal de Campina Grande (UFCG).

Os títulos dos projetos são:

 - **PIBIC**: Concepção e Avaliação de uma Ferramenta de Inteligência Artificial para a Geração de Laudos de Citologia Oncótica.

 - **PIBITI**: Desenvolvimento de um Sistema de Geração Automática de Laudos Médicos por Reconhecimento de Voz e Processamento de Linguagem Natural .

## Estado atual

Atualmente, devido a uma mudança de foco no setor médico alvo da pesquisa, os trabalhos se concentram em **treinar e avaliar _LLMs_ de código aberto para auxiliar profissinais de Radiologia na classificação e geração de laudos médicos de Radiografia de Tórax**.
